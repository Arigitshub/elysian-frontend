> The first-of-its-kind virtual therapy platform designed for absolute immersion, complete privacy, and psychological flow.

Elysian Soul represents the **Apex Edition** of digital mental health care. By combining high-fidelity 3D WebGL rendering with a proprietary, self-hosted psychological AI core, we provide a sanctuary for the mind that is entirely free from third-party observation.

---

## ✨ Apex Features

- **🎭 Living 3D Presence:** A photorealistic therapist rendered in real-time via React Three Fiber, featuring procedural breathing, blinking, and empathic head tracking.
- **🧠 Synaptic AI Integration:** Seamlessly connected to the **Elysian AI Engine**, a "No Third-Party" psychological model designed for deep empathic resonance.
- **🌊 Flow-State UI:** A masterwork interface using Emerald & Gold aesthetics, micro-grain textures, and glassmorphic blurs to promote a state of calm and trust.
- **🔒 Absolute Privacy:** Zero API calls to external LLMs. Every thought shared stays within the Elysian ecosystem.
- **🍃 Zen-Blur Notifications:** Minimalist, high-end feedback systems that maintain therapeutic focus.

## 🚀 Getting Started

1.  **Clone** the repository.
2.  Install dependencies: `npm install`
3.  Set up the [Elysian Backend](https://github.com/Arigitshub/elysian-backend).
4.  Run the development server: `npm run dev`
5.  Open `http://localhost:3000` to begin your session.
